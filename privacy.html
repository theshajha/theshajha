Privacy Policy

Personal site and tools at theshajha.com

I'm Shashank Jha. This site and the personal tools I publish (including a Google Workspace CLI that uses a Google OAuth client) are for my own use.

What data is accessed

When you sign in with Google, the tool only accesses the Google account data you authorize — for example Gmail, Calendar, Drive, or Search Console — so it can run automation for that same account owner. Nothing else is requested.

What is stored

OAuth tokens live on the user's own machine so the CLI can keep working. I do not run a cloud store for this data.

What I don't do

I don't sell data, show ads, or share account data with third parties. Google is the API provider; data goes through their APIs so the tool can do what you asked.
